# Exercise 3: Multiple Pointers

> **Objective:**
>
> Practice using multiple variables and pointers together.

---

## Topics Covered

- Multiple pointers
- Independent memory addresses

---

## Tasks

1. Create two integer variables.
2. Create two pointers.
3. Make each pointer point to a different variable.
4. Print the values using dereferencing.

---

## Expected Learning

You should understand:

- Different pointers can point to different variables
